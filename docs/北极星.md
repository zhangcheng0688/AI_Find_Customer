# 北极星（已对齐，2026-09-10）

这是 **你自己的产品**：一套可白标的 Agent 平台。

```
你的 UI / 产品壳（品牌、租户、Bot、对话页）
        │
        ├─ 扣子 Coze Studio     编排底座（Agent / 工作流）
        └─ RAGFlow              知识底座（文档、检索、引用）
```

**不是** 电缆询价系统，也不是「先做企微催办再换皮」。PRD v1.1 里的电缆/制造只是当时写的行业举例，**不进入本仓库的产品叙事**。

| 层 | 谁做 | 7 天要看见什么 |
|----|------|----------------|
| 扣子底座 | 开源 Coze Studio（Apache 2.0） | 能起来、能配模型、能跑一个 Bot |
| 知识 | RAGFlow（Apache 2.0） | 能上传文档、检索带引用 |
| 白标壳 | 自研（本仓库 `apps/console` + `apps/api`） | 自己的 Logo/名称/主题；对话走你的页面，不把扣子原生后台当对外产品 |

禁止：Dify / n8n / FastGPT / MaxKB 当内核。扣子开源缺的多租户/去品牌，用壳补，不要换底座。
