# 项目简报 — 企业级白标 AI Agent 工厂

## 一句话

做可白标的 **组织级 Agent 工厂**（SaaS 多租户优先）：在平台搭机器人 → 挂企微/飞书 → **可人工调用，也可无人值守推进长程任务**（催办、升级、转人工）。

## 四层底座（不要合并成「一个开源项目」）

1. **交互**：企微/飞书 + 自研 `channel-gateway`
2. **编排**：Coze Studio（Apache 2.0）— 可视化工作流 / Agent
3. **知识**：RAGFlow（Apache 2.0）
4. **主动长程**：自研 **Task/Mission 任务引擎** + Activepieces（MIT 核心，禁 EE）

产品壳（租户/白标/配额/Bot/模板/审计/**任务引擎**）= 真正卖的软件，必须自研。

## 与个人 Agent 的区别

不是 Grok/OpenClaw 那种「人喊一句才动」。要有任务状态机、超时催办、升级、审计、多租户隔离。

## 技术偏好

- Monorepo：`apps/api`（含 mission）、`apps/console`、`apps/channel-gateway`、`deploy/compose`、`templates/`、`docs/`
- API：Go 或 NestJS（二选一，选了就锁死）
- 前端：React + TS + Ant Design Pro
- DB：PostgreSQL；缓存：Redis；对象存储：MinIO
- 一期租户：逻辑隔离 + 引擎 workspace 映射

## 禁止

Dify / n8n / FastGPT / MaxKB 作可白标多租户内核；用 OpenClaw 替换 Coze 或任务引擎。

## 首发闭环（P1 目标）

企微询价 → RAG 检索 → 回复/报价草稿 → 企微发出 → **任务引擎** 驱动超时催办/升级。
