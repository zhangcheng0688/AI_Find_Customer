# 项目简报 — 白标 Agent（扣子 + RAGFlow）

## 一句话

做 **你自己的白标 Agent 产品**：底下用开源 **扣子 Coze Studio** 做编排、**RAGFlow** 做知识；上面用自研控制台做品牌、租户和对话 UI。不是电缆询价工具。

## 三层（不要合成「一个开源项目」）

1. **产品壳 / UI（自研，真正对外卖的）**：租户、白标、Bot、对话页、权限
2. **编排底座**：Coze Studio（Apache 2.0）— Agent / 可视化工作流
3. **知识底座**：RAGFlow（Apache 2.0）— 文档、检索、引用

渠道网关（企微/飞书）和长程任务引擎是后挂能力，**不是这 7 天的产品定义**。

## 与「直接用扣子」的区别

用户进的是你的页面和品牌；扣子原生 `:8888` 只给搭建者/实施，不当对外产品。多租户和去品牌由壳补（开源扣子本身缺完整 SaaS 白标）。

## 技术偏好

- Monorepo：`apps/api`、`apps/console`、`deploy/compose`、`templates/default-agent`、`docs/`
- API：Go + Gin（已锁定）
- 前端：React + TS + Ant Design Pro 质感（你可以继续把 UI 做漂亮）
- DB：PostgreSQL；缓存：Redis；对象存储：MinIO

## 禁止

Dify / n8n / FastGPT / MaxKB 作可白标内核。

## 7 天闭环

你的 UI 对话 → 壳验租户 → RAGFlow 检索 → 扣子 Agent 作答 → 引用展示在你的页面上。
