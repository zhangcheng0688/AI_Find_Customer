## 表 A · 必问问题（需求表原题）逐条答复

| 编号 | 模块 | 原问题 | 答复（可直接给客户） | 结论 |
| --- | --- | --- | --- | --- |
| Q1 | P1 海关 | 覆盖哪些数据源/国家？更新周期？ | **公开源**：美国进境提单类公开记录（企业级进口商），更新约 T+1～T+7；UN Comtrade / EU COMEXT 覆盖全球 HS×国家**汇总**，无企业名单，月/年更。**企业级全球名单**需授权商业库（ImportGenius / Panjiva / Volza / Trademo 等 API），国家覆盖与更新周期以所购供应商合同为准（常见周更/月更）。现有系统已能对**已知公司**检索上述站点的公开摘要页作证据，**不能**在未授权情况下按 HS 码扫出全球进口商名录。 | 有条件承诺 |
| Q2 | P1 爬虫 | 爬虫能否处理 JS 动态站？反爬/IP 策略？ | **能处理一部分。** 现网抓取是 Jina Reader（可转 Markdown，覆盖中等动态页）；仓库已有 Playwright 对比脚本，但未进生产依赖。方案：直连 → Jina → 无头浏览器兜底。反爬：遵守 `robots.txt`、低并发、失败退避；可选住宅代理。验证码/登录墙**跳过该页**，不破解。 | 可承诺（三级瀑布） |
| Q3 | P1 维护 | 目标站改版后维护周期/成本？ | 抽取以通用结构 + LLM 为主，不为每家客户站写死 XPath，常规改版含在年维护里、不按站收费。客户指定必须盯死的站点另立项。海关商业源改版由供应商承担，我们换 API 适配。 | 可承诺 |
| Q4 | P1 数据 | 数据能否导出？所有权归谁？ | **能导出** CSV / JSONL（含证据 URL）。结构化线索导出后归客户自用。我们库内按任务/租户隔离，原始网页缓存定期删除。商业海关**原始库**受上游协议约束，不可转售、不可当公共数据集再分发。客户自有 CRM 我们不开发、不托管业务分析。 | 可承诺 |
| Q5 | P1 清洗 | 「破产/停业」怎么判定？过滤规则能否自定义？ | **不能 100% 判定破产。** 三档：① 公司注册处状态（若该国有开放接口）→ `registry_status`；② 海关窗口内无记录 + 官网不可达 → `likely_inactive`；③ 其余 → `unknown`。货代/同行/空邮箱（仅语法+MX，不做 SMTP 探测）/最低进口频次均可配置开关与阈值。意图评 A/B/C。 | 可承诺（不确定项如实标注） |
| Q6 | P1 合规 | 是否只采公开信息？IP 被封责任？ | **只采公开页**，不黑客、不绕登录、不撞库。目标站封 IP 导致该条线索缺失，不视为系统故障；我们换代理或跳过，不提供绕过验证码的能力。因客户要求采集非公开数据而产生的法律责任由提出方承担——方案默认拒绝此类需求。 | 可承诺 |
| Q7 | P2 嵌入 | WordPress 好不好嵌？部署要多久？ | 一段 JS / 短代码，WP 主题 footer 或插件即可；**当前 slam.systems 是静态站不是 WP**，同一段脚本两种宿主都能挂。脚本嵌入本身是小时级；真正耗时是知识库准备（手册、FAQ、禁答清单）和多语校对。 | 可承诺 |
| Q8 | P2 知识库 | 客户能否自己更新知识库/话术？ | **能。** 后台上传 PDF/Markdown、勾选官网 URL 再抓取、编辑拒答与转人工规则；保存后重建索引。不改代码。 | 可承诺 |
| Q9 | P2 语言/幻觉 | 支持哪些语言？AI 能否锁死知识库？ | 首期建议 **德 / 英 / 中**（与现站 `lang=de` 及外贸场景对齐），其它语种按页加。**能锁死**：检索不到就说「需要人工」，禁止编型号、价格、认证、交期。这是硬规则，不只靠 prompt。 | 可承诺 |
| Q10 | P2 GDPR | GDPR？数据归谁？ | 对话与线索默认客户所有。建议 EU 区部署、上线前签 DPA、Cookie/对话同意、默认保留 30 天、支持导出与删除。不把对话拿去训练基础模型。不接客户 CRM 分析模块。 | 可承诺（托管区需客户确认） |
| Q11 | P2 SEO | SEO/GEO 具体做什么？「不改原功能」能否写进合同？ | 聊天脚本 `defer`，不改下单/表单/导航逻辑。SEO 另做轻量清单：title/description、FAQ/Product JSON-LD、sitemap、多语时 hreflang。GEO（生成式引擎引用）= 可引用的结构化产品页 + 知识库同源，不保证出现在 ChatGPT/Google AI 答案里。**「不改原有业务功能」可按清单写进合同**，SEO 改动可回滚。 | 可承诺 |
| Q12 | P2 改版 | 官网改版维护费？如何验收优化？ | 小部件与主题皮肤分离；大改版通常只调 CSS/挂载位置。SEO 验收用 Search Console 索引、富结果、Core Web Vitals，**不承诺搜索排名**。 | 可承诺（不承诺排名） |
| Q13 | P3 分发 | 是否 OAuth？不共享密码？ | **是。** Facebook/Instagram（Meta）、LinkedIn、YouTube、X 全部走官方 OAuth。不收集、不存储平台密码。 | 可承诺 |
| Q14 | P3 分发 | 能否一键解绑？ | **能。** 撤销本系统 token，并提示客户同时在平台安全页解除授权。 | 可承诺 |
| Q15 | P3 分发 | YouTube 是否官方 API？ | **是。** 上传走 YouTube Data API `videos.insert`（可恢复上传）。不用非官方客户端模拟登录。 | 可承诺 |
| Q16 | P3 分发 | 文件有无限制？ | **有，且完全跟随各官方 API**，后台展示限额。YouTube：最长约 12 小时或 256GB（账号权限另有限制）；Meta/LinkedIn/X 按时长、体积、编码各不相同。超限在发布前拦截并提示，不静默失败。 | 可承诺 |
| Q17 | P3 筛客 | 用哪个 LLM？ | 与现网 Hunter 同一套 **LiteLLM 网关**，默认可配 `gpt-4o-mini`（抽取）+ `gpt-4o`（推理），可换成 Anthropic / OpenRouter / GLM / MiniMax 等。筛客多模态（图+文）用带视觉的模型。具体型号写进部署配置，可换，不绑死一家。 | 可承诺 |
| Q18 | P3 筛客 | YouTube STT 语言与准确率？ | **对客户自己的频道**：官方 Captions API，语言以频道已有字幕为准（常见 en/de 等）。**对他人视频**：官方 API **不能**任意下载字幕或做全网 STT。筛客应用标题、描述、公开评论 + 关键词；若要对公开视频做语音识别，需另采合规 STT，准确率随口音/噪音变化，**必须试点后给数字，不预打包票**。 | 有条件承诺 |
| Q19 | P3 筛客 | 关键词组能否自定义？ | **能。** 多组关键词、包含/排除、按平台开关，保存即生效。 | 可承诺 |
| Q20 | P3 筛客 | 平台改 UI 后维护费？ | 检索与分发走**官方 API**，不依赖页面 CSS。API 变更含在年维护；若客户坚持 RPA 点页面，UI 一变就要单独报价——**本方案不采用 RPA**。 | 可承诺（因不做 RPA） |
| Q21 | P3 风控 | 底层是 API 还是 RPA/云手机？ | **官方 API。** 不做云手机、不做模拟点击、不共享实体/虚拟手机号矩阵。 | 可承诺 |
| Q22 | P3 风控 | 账号有什么风险？ | 即使用官方 API，超量、重复、垃圾内容仍可能被限流或封号，责任在内容与操作频率。自动赞/粉风险最高，故**不提供该能力**。官方发帖风险低于 RPA，但不能为零。 | 可承诺（风险说明） |
| Q23 | P3 风控 | 各平台每日互动上限能否自定义？ | 发帖频率可按平台配置上限。**自动赞/粉不做**，因此不提供「自动互动日限额」——若以后只做「名单+深链提醒销售去点」，提醒条数可配。 | 不能承诺自动互动；可配发帖上限 |
| Q24 | P3 风控 | 封号后如何补救？ | 提供：操作审计日志、立即停发、解绑、合规申诉材料清单（时间、API 调用、内容 ID）。**不承诺能解封，不承担封号赔偿**，也无法保证平台申诉成功。建议客户用商务号、开双账号备份。 | 不能承诺解封 |
