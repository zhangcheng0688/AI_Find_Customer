B-2.1 / Sport Media

SLAM.SYSTEMSCOR Family

我们的模块化系统让现代体育多媒体环境化繁为简，轻松掌控。将智能融入系统，让操作清晰直观。

通过集中式操作理念，SLAM.SYSTEMS 将复杂的现场工作流程整合到一个直观的用户界面中。自动化处理、预设流程与紧密集成的硬件，共同打造稳定可靠、清晰高效的现场运行环境。

我们的解决方案将体育媒体播控、实时数据、记分牌、计时、广播制作集成、LED 系统与视觉传播融为一体，带来流畅而智能的整体体验。

Complexity belongs in the system. Simplicity belongs to the user.

面向专业体育环境的智能媒体播控解决方案，将实时数据、媒体内容、控制与视觉传播紧密相连。

SLAM DECKCOR (frontend)
中央操作与控制平台连接操作人员和整个系统，无论是单个 LED 系统，还是复杂的联网显示环境，都能轻松掌控。

SLAM SCORECOR (frontend)
SLAM.SYSTEMSCOR Family 中专为专业记分牌和实时信息系统打造的前端。它融合官方比赛数据、赛事逻辑与视觉传播，为现代体育展示提供可靠的解决方案。

SLAM.SYSTEMSCOR Family 的中央控制与管理层，支持创建、管理和控制复杂的媒体布局、现场流程及视觉场景，从单屏应用到覆盖整个体育场和活动场馆的一体化多媒体体验。

SLAM PLAYCOR (runtime)
作为 SLAM.SYSTEMSCOR Family 的运行组件，媒体播放器为数字内容提供可靠的执行层。SLAM PLAYCOR 通过高性能运行架构输出媒体内容和数据，适用于单屏应用及多输出通道同步运行的现场环境。

SLAM TIMECOR (runtime)
SLAM.SYSTEMSCOR Family 的辅助运行模块，用于在赛场之外显示最新比赛信息，例如球队和裁判更衣室、贵宾区或控制室。

SLAM DECKCOR

The Intelligent Control Deck for Professional Sports Communication

SLAM DECKCOR 是 SLAM.SYSTEMSCOR Family 的中央操作与控制平台，连接操作人员与系统，为现代体育和活动环境提供直观的控制界面。

通过这一平台，媒体内容、LED 系统和现场流程都能得到简单而可靠的控制。

SLAM DECKCOR 专为专业体育环境开发，兼顾全局掌握与简便操作。iPad Pro 上的图形界面带来直观的工作流程，可集中控制单个 LED 系统及复杂的联网显示环境。即使面对高要求的现场场景，操作依然清晰有序，让一名操作人员也能从容监控和控制整个流程。

系统架构以稳定性、灵活性和可扩展性为核心。模块化设计使 SLAM DECKCOR 能够适应不同需求，并可随时扩展。

SLAM SCORECOR

Connecting sport data. Connecting visual communication.

SLAM SCORECOR 是 SLAM.SYSTEMSCOR Family 中的专业前端，旨在以简单、灵活、可靠的方式控制专业记分牌与实时信息系统。通过结构清晰的 iPad Pro 操作界面，裁判或操作人员可在赛事进行时安全、高效地管理所有相关内容。

SLAM SCORECOR 可针对不同运动项目、联赛和赛事单独配置，灵活适应比赛规则、数据结构、专属布局及视觉呈现等需求。与 SLAM PLAYCOR 配合后，可构成功能强大的独立运行方案，适用于不同 LED 记分牌规格和客户定制显示需求。

随着需求增长，可通过 SLAM.SYSTEMSCOR Family 的其他组件扩展系统。SLAM DECKCOR 与 SLAM DIRECTORCOR 共同构建中央管理平台，统筹比赛信息、赞助商与广告传播、媒体内容、记分牌上的直播电视及其他视觉元素。

集成的广播接口可将官方比赛时间和结果与外部制作系统同步。SLAM SCORECOR 还支持其他数据源，例如 Kinexon 实时定位系统（RTLS），采集位置与运动数据，并将其转化为 LED 记分牌上的视觉信息。

SLAM DIRECTORCOR 支持提前编排多媒体演出，并在现场自动执行。媒体序列、视觉效果以及灯光、音响等外部系统可按统一时序集成，作为整体现场体验的一部分进行控制。

SLAM SCORECOR 将赛事逻辑、实时数据、媒体内容与视觉传播融合为面向现代体育展示的智能前端。

Control

SLAM DIRECTORCOR

The Intelligent Control Layer Behind Every Live Experience

SLAM DIRECTORCOR 是用于创建、管理和执行专业媒体布局及现场场景的中央平台。通过基于图层的媒体序列、视觉效果和外部系统组合，SLAM DIRECTORCOR 可精准构建灵活扩展的现场体验，从单屏应用到体育场、活动场馆及其他现场环境中的完整多媒体演出。

在 SLAM.SYSTEMSCOR Family 中，SLAM DIRECTORCOR 负责内容的集中管理，以及针对指定输出系统的缩放、定位和时序控制。内容可按设定时间、尺寸和位置自动呈现在 LED 系统或其他显示屏上。

系统将创意表现与智能控制相结合。媒体和电视内容、数字标牌应用，以及灯光、音响和第三方外围设备等外部系统，通过明确的接口集成并集中控制。这一高性能平台让内容、技术与流程精准协同，为专业现场传播带来充分的掌控力和清晰可靠的操作体验。

整个 SLAM.SYSTEMS 产品家族的开发始终注重清晰的系统架构、智能集成和简洁的操作理念。无论新增扩展还是升级至未来的系统世代，操作人员都能沿用熟悉的 SLAM.SYSTEMS 界面和系统逻辑。各组件相互连接，构建强大的现场环境，并保持一致的用户体验。

Runtime

SLAM PLAYCOR

The intelligent runtime engine for reliable content execution

SLAM PLAYCOR 将 SLAM.SYSTEMS 的可扩展软件架构延伸至可靠的媒体输出端。从独立应用到同步运行的体育场及现场环境，SLAM PLAYCOR 为专业现场应用提供精准、同步且可靠的播放，延迟低于 18 ms。

每台 SLAM PLAYCOR 都能独立于整体系统处理和输出内容。SLAM DIRECTORCOR 通过集中分配与时序控制，将各播放器组成智能协同的整体系统。

针对从 HD 到 8K/UHD 的不同输出场景，SLAM.SYSTEMS 采用成熟的硬件方案，并融入超过 25 年的 OOHDT 经验。这些积累为可靠的解决方案、稳定运行和清晰的系统架构奠定基础，帮助实现长期经济高效的运营。

对于对可用性和运行可靠性有更高要求的现场活动，如组织者或赛事提出相应要求，SLAM PLAYCOR 可与 SLAM.SYSTEMS LED 显示屏共同采用冗余系统架构运行。

SLAM TIMECOR

Live Match Information. Beyond the Field.

SLAM TIMECOR 是 SLAM.SYSTEMSCOR Family 的辅助运行模块，用于在赛场之外显示最新比赛信息，例如球队和裁判更衣室、贵宾区或控制室。

比赛期间，场外同样需要了解比赛时间与比分。尤其在休息期间，球队和赛事官员需要快速查看当前比分及剩余休息时间。SLAM PLAYCOR 可将这些信息可靠地输出到显示屏上。

SLAM TIMECOR 在冰球赛事中尤为实用：休息期间，球员和工作人员可在相应球队区域及功能空间内，随时查看当前比分和剩余比赛时间。
